01 / 개관

학기의 큰 그림

2학기 전체가 세 단계로 이어집니다. 뒤 단계는 앞 단계 위에서만 성립하므로, 한 단계를 놓치면 다음이 무너집니다.

STEP 1 · 2~3주

구조를 바꾼다

배열과 리스트로는 “A와 B가 연결되어 있다”를 표현할 수 없습니다. 트리와 그래프로 관계 자체를 자료구조에 담습니다.

STEP 2 · 4~6주

순서를 만든다

STEP 3 · 7~9주

빠르게 찾는다

자료가 많아지면 전부 확인할 수 없습니다. 이진 탐색과 해싱으로 찾는 비용을 줄이는 방법을 배웁니다.

1학기와 어떻게 이어지는가

01 / 개념

정렬은 왜 배우나

수업 슬라이드 chapter 4 도입부를 정리한 것입니다.

정렬이란

자료를 일정 순서대로 나열하는 것

물건을 크기 순으로 오름차순이나 내림차순으로 나열하는 것. 정렬은 컴퓨터공학을 포함한 모든 과학기술 분야에서 가장 기본적이고 중요한 알고리즘 중 하나입니다. 자료 탐색에 있어서 필수적이기 때문입니다.

정렬의 대상

레코드와 키(key)

일반적으로 정렬시켜야 될 대상은 레코드(record)입니다. 레코드는 필드라는 더 작은 단위로 구성되고, 그중 키(key) 필드로 레코드와 레코드를 구별합니다.

어떤 정렬을 골라야 할까

모든 경우에 최적인 정렬 알고리즘은 없습니다. 따라서 각 응용 분야에 적합한 정렬 방법을 사용해야 합니다. 고를 때의 기준은 두 가지입니다 — 비교 횟수와 이동 횟수.

단순하지만 비효율적인 방법

03 / 코드

알고리즘 5가지와 핵심 코드

아래 코드는 수업 슬라이드에 실린 원문 그대로입니다. 시뮬레이터에서 본 움직임이 코드의 어느 줄에서 일어나는지 짚어 보세요.

1

선택 정렬SELECTION SORT

O(n²)

초기에는 왼쪽 리스트는 비어 있고, 정렬할 숫자들은 모두 오른쪽 리스트에 존재합니다. 오른쪽에서 가장 작은 값을 골라(select) 왼쪽 끝에 붙이는 것을 반복합니다.

수업 슬라이드 원문 · C

#define SWAP(x, y, t) ( (t)=(x), (x)=(y), (y)=(t) )

void selection_sort(int list[], int n) {
    int i, j, least, temp;
    for(i=0; i<n-1; i++) {
        least = i;
        for(j=i+1; j<n; j++)    // 최솟값 탐색
            if(list[j]<list[least]) least = j;
        SWAP(list[i], list[least], temp);
    }
}
핵심 안쪽 for문이 최솟값의 위치(least)를 찾기만 하고, 교환은 바깥 for문에서 한 번만 일어납니다. 그래서 비교는 많아도 교환 횟수가 가장 적습니다.
2

삽입 정렬INSERTION SORT

O(n²)

정렬되어 있는 부분에 새로운 레코드를 올바른 위치에 삽입하는 과정을 반복합니다. 카드를 손에 쥐고 한 장씩 끼워 넣는 것과 같습니다.

수업 슬라이드 원문 · C

void insertion_sort(int list[], int n)
{
    int i, j, key;
    for(i=1; i<n; i++){
        key = list[i];
        for(j=i-1; j>=0 && list[j]>key; j--)
            list[j+1] = list[j];
        list[j+1] = key;
   }
}
핵심 안쪽 for문의 조건 list[j]>key 가 거짓이 되는 순간 멈춥니다. 그래서 이미 정렬된 자료에서는 거의 움직이지 않아 O(n) 에 가까워집니다. 시뮬레이터에서 학습지 ③(4 5 9 3 6 8 7 1) 앞부분이 빠르게 지나가는 이유입니다.
3

버블 정렬BUBBLE SORT

O(n²)

인접한 2개의 레코드를 비교하여 순서대로 되어 있지 않으면 서로 교환합니다. 큰 값이 거품처럼 뒤로 떠오릅니다.

수업 슬라이드 원문 · C

void bubble_sort(int list[], int n)
{
    int i, j, temp;
    for(i=n-1; i>0; i--){
        for(j=0; j<i; j++)
           if(list[j]>list[j+1])
               SWAP(list[j], list[j+1], temp);
   }
}
핵심 비교할 때마다 곧바로 교환하므로 이동(교환) 횟수가 가장 많습니다. 시뮬레이터에서 같은 자료로 선택 정렬과 버블 정렬의 교환 횟수를 비교해 보세요.
4

셸 정렬SHELL SORT

O(n^1.5)

전체 리스트를 일정 간격(gap)의 부분 리스트로 나눈 후, 나뉜 각각의 부분 리스트를 삽입 정렬합니다. 간격을 절반씩 줄여 가며 반복합니다.

수업 슬라이드 원문 · C

inc_insertion_sort(int list[], int first, int last, int gap) {
    int i, j, key;
    for(i=first+gap; i<=last; i=i+gap){
        key = list[i];
        for(j=i-gap; j>=first && key<list[j];j=j-gap)
            list[j+gap]=list[j];
        list[j+gap]=key;
    }
}

void shell_sort( int list[], int n ) {
    int i, gap;
    for( gap=n/2; gap>0; gap = gap/2 ) {
        if( (gap%2) == 0 ) gap++;
        for(i=0;i<gap;i++)  // 부분 리스트의 개수는 gap
            inc_insertion_sort(list, i, n-1, gap);
  }
}
핵심 inc_insertion_sort 는 삽입 정렬과 똑같은데 1칸씩이 아니라 gap칸씩 건너뜁니다. 멀리 떨어진 값을 미리 대충 옮겨 두기 때문에, 마지막 gap=1 삽입 정렬이 훨씬 빨리 끝납니다.
5

퀵 정렬QUICK SORT

평균 O(n log n)

평균적으로 가장 빠른 정렬 방법입니다. 분할정복법을 사용하여 리스트를 2개의 부분 리스트로 비균등 분할하고, 각각의 부분 리스트를 다시 퀵 정렬(재귀호출)합니다.

수업 슬라이드 원문 · C

int partition(int list[], int left, int right) {
   int pivot, temp, low, high;
   low = left;
   high = right+1;
   pivot = list[left];
   do {
            do
                low++;
            while(low<=right && list[low]<pivot);
            do
                high--;
            while(high>=left && list[high]>pivot);
            if(low<high) SWAP(list[low], list[high], temp);
   } while(low<high);
슬라이드가 여기서 끝납니다 수업 자료의 코드는 } while(low<high); 까지만 실려 있습니다. 실제로는 아래 두 줄이 더 있어야 완성됩니다. 시험 대비용으로 꼭 기억해 두세요.

이어지는 부분

   SWAP(list[left], list[high], temp);   // 피벗을 제자리로
   return high;                          // 피벗의 최종 위치를 돌려줌
}

void quick_sort(int list[], int left, int right) {
   if(left<right) {
      int q = partition(list, left, right);
      quick_sort(list, left, q-1);          // 피벗 왼쪽
      quick_sort(list, q+1, right);         // 피벗 오른쪽
   }
}
핵심 피벗은 한 번 자리를 잡으면 다시 움직이지 않습니다. 시뮬레이터에서 보라색 피벗이 초록으로 바뀌는 순간이 바로 그 지점입니다. 피벗을 어떻게 고르느냐에 따라 성능이 달라져서, 이미 정렬된 자료에 첫 원소를 피벗으로 쓰면 최악 O(n²) 가 됩니다.
+

합병 정렬MERGE SORT

O(n log n)

리스트를 두 개의 균등한 크기로 분할하고, 분할된 부분 리스트를 정렬한 다음, 정렬된 두 개의 부분 리스트를 합하여 전체 리스트를 정렬합니다.

  • 분할 — 배열을 같은 크기의 2개 부분 배열로 나눈다.
  • 정복 — 부분 배열을 정렬한다. 크기가 충분히 작지 않으면 재귀호출로 다시 분할정복을 적용한다.
  • 결합 — 정렬된 부분 배열을 하나의 배열로 통합한다.
퀵 정렬과의 차이 퀵 정렬은 비균등 분할(피벗 기준), 합병 정렬은 균등 분할(가운데 기준)입니다. 그래서 합병 정렬은 자료가 어떻게 생겼든 항상 O(n log n)이지만, 추가 메모리가 필요합니다. 수업 슬라이드에는 그림으로만 나와 있어 여기서는 코드를 싣지 않았습니다.

05 / 점검

확인 문제

먼저 스스로 답을 생각한 뒤 눌러서 확인하세요.

Q1 같은 자료를 선택 정렬과 버블 정렬로 각각 돌리면, 교환 횟수는 어느 쪽이 더 많을까? 그 이유는?

버블 정렬이 훨씬 많습니다. 버블 정렬은 이웃을 비교할 때마다 곧바로 교환하지만, 선택 정렬은 안쪽 반복에서 최솟값의 위치만 기억해 두었다가 바깥 반복마다 딱 한 번만 교환하기 때문입니다. 비교 횟수는 둘 다 약 n²/2 로 비슷합니다.

Q2 이미 오름차순으로 정렬된 배열에 삽입 정렬을 적용하면 시간 복잡도는 어떻게 될까?

O(n) 이 됩니다. 안쪽 for문의 조건 list[j]>key 가 첫 비교에서 바로 거짓이 되어 한 번도 밀지 않고 빠져나오기 때문입니다. 바깥 for문만 n−1번 도는 셈이라 삽입 정렬은 거의 정렬된 자료에서 가장 유리한 알고리즘입니다.

Q3 퀵 정렬에서 이미 정렬된 배열에 대해 맨 왼쪽 원소를 피벗으로 고르면 어떤 일이 생길까?

피벗보다 작은 값이 하나도 없어서 분할이 1개와 n−1개로 극단적으로 치우칩니다. 이 상태가 매번 반복되어 재귀 깊이가 n이 되고, 결과적으로 최악의 경우 O(n²) 가 됩니다. 그래서 정렬 학습지 3번처럼 왼쪽·중간·오른쪽의 중간값을 피벗으로 고르는 방법을 씁니다.

Q4 셸 정렬에서 간격(gap)을 두는 이유는 무엇일까?

삽입 정렬은 값을 한 칸씩만 옮기기 때문에, 멀리 떨어진 곳에 있어야 할 값이 제자리를 찾으려면 아주 많이 움직여야 합니다. 셸 정렬은 gap칸씩 건너뛰며 미리 대충 자리를 잡아 두어 이 이동량을 크게 줄입니다. 마지막에 gap=1 로 삽입 정렬을 하면 이미 거의 정렬된 상태라 금방 끝납니다.

Q5 정렬 알고리즘을 고를 때의 두 가지 기준은 무엇인가?

비교 횟수와 이동(교환) 횟수입니다. 자료 하나의 크기가 크면 옮기는 비용이 커지므로 이동 횟수가 적은 선택 정렬이 유리할 수 있고, 비교 자체가 비싸면 비교 횟수가 적은 쪽이 유리합니다. 모든 경우에 최적인 정렬 알고리즘은 없습니다.

04 / AI

AI 활용 3단계

이 과제는 생성형 AI로 아이디어와 자료를 얻은 뒤, 그것을 검토하고 고쳐서 제출하는 방식입니다. 아래 순서대로만 하면 규정을 지키면서 점수를 올릴 수 있습니다.

1

재료 모으기 — AI에게 아이디어와 자료를 받는다

다음 장의 프롬프트를 그대로 복사해 붙여 넣으면, AI가 주제 후보·비교표·개념 정리를 만들어 줍니다. 이건 내 답이 아니라 재료입니다.

2

검토하기 — 사실을 확인하고 내 주제에 맞는 것만 고른다

AI는 시간 복잡도나 알고리즘 설명을 틀리게 말할 때가 있습니다. 교과서와 수업 필기로 대조하고, 내 주제와 맞지 않는 내용은 버립니다. 프롬프트마다 AI가 [내가 직접 확인해야 할 것] 목록을 만들어 주도록 해 두었습니다.

3

다시 쓰기 — 내 언어로 옮기고, 마지막에 한 번 더 점검받는다

고른 재료를 보지 않고 내 말로 씁니다. 다 쓴 뒤 P5로 채점기준에 대조하고, P6로 그대로 베낀 문장이 남아 있지 않은지 확인합니다.

해도 되는 것

  • 자료 검색과 전문 자료의 요약
  • 주제 후보와 아이디어를 여러 개 받아 보기
  • 알고리즘 비교표·개념 설명 받기
  • 내가 쓴 글의 사실관계 확인받기
  • 내 논리에서 빠진 부분을 지적받기

하면 안 되는 것

  • AI가 써 준 문장을 그대로 옮겨 적기
  • 항목 전체를 통째로 대신 작성시키기
  • 사실 확인 없이 AI 설명을 그대로 믿기
  • 출처와 AI 활용 범위를 밝히지 않기
결과물 산출에 AI를 활용한 내용을 그대로 작성할 경우, 해당 평가 요소의 최하점이 부여됩니다. AI 답변 중 그대로 베끼고 싶어지는 문장이 나왔다면, 그게 바로 베끼면 안 되는 문장입니다. 읽고 창을 닫은 뒤 내 말로 다시 쓰세요. 그 과정이 이 과제가 평가하려는 능력 그 자체입니다.

보고서 끝에 반드시 적을 것

참고 자료의 출처와 AI를 어디에 어떻게 썼는지를 두세 줄로 적어 주세요. 예: “정렬 알고리즘의 시간 복잡도 비교표를 받아 참고함. 2차 정렬 기준이 필요하다는 점을 확인한 뒤 내 주제에 맞게 다시 판단하여 작성함.” 이 기록이 있으면 감점되지 않습니다. 없으면 감점됩니다.

import random, math

def seq_count(data, target):
    for i, v in enumerate(data):
        if v == target:
            return i + 1
    return len(data)

def bin_count(data, target):
    low, high, c = 0, len(data) - 1, 0
    while low <= high:
        mid = (low + high) // 2
        c += 1
        if data[mid] == target:
            return c
        elif data[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return c

TRIALS = 20      # 무작위로 20번 찾아본 평균을 냅니다
print(f"{'자료 크기':>12} | {'순차 탐색':>10} | {'이진 탐색':>10} | {'몇 배':>8} | {'log2(n)':>8}")
print("-" * 62)

for n in [10, 100, 1000, 10000, 100000, 1000000]:
    data = list(range(n))
    s = b = 0
    for _ in range(TRIALS):
        t = random.randrange(n)
        s += seq_count(data, t)
        b += bin_count(data, t)
    s //= TRIALS
    b //= TRIALS
    ratio = s / b if b else 0
    print(f"{n:>12,} | {s:>10,} | {b:>10,} | {ratio:>7.1f}배 | {math.log2(n):>8.1f}")
