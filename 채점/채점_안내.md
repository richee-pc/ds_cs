# 채점 안내

## 학생은 무엇을 내는가

학생이 만든 HTML 파일에는 쓴 글이 **들어 있지 않습니다.**
입력한 내용은 그 브라우저에만 저장되기 때문입니다.

학생은 파일 맨 아래 **「제출 파일 만들기」** 를 눌러야 합니다.
그러면 쓴 글이 박힌 새 파일이 내려받아집니다.

```
3반_7번_김서연_수행평가 2_제출.html
```

**이 파일**을 받으십시오. 원래 파일을 그대로 받으면 빈 양식입니다.

파일 이름이 `_제출.html` 로 끝나지 않으면 잘못 낸 것입니다.

---

## 제출 파일에 담기는 것

브라우저로 열면 사람이 읽을 수 있게 나옵니다.

- 반 · 번호 · 이름, 제출 파일을 만든 때
- 항목마다 **학생이 쓴 글**
- 「대조용 — AI 초안」 접힘 — 눌러서 견주어 볼 수 있습니다
- **실행 기록** — 학생이 시뮬레이터를 돌린 결과 전부

안 쓴 항목은 빨간 글씨로 **(쓰지 않았습니다)** 라고 나옵니다.

파일 안에는 기계가 읽는 자료도 함께 들어 있어 아래 도구로 표를 만들 수 있습니다.

---

## 채점표 만들기

1. 이 폴더에 `제출` 폴더를 만들고, 받은 html 파일을 모두 넣습니다.
2. 아래를 실행합니다.

```bash
python 모으기.py
```

만들어지는 것

| 파일 | 쓰임 |
| --- | --- |
| `채점표.csv` | 엑셀로 열어 보는 표. 학생 × 항목별로 한 줄 |
| `채점자료.json` | 클로드와 함께 채점할 때 쓰는 자료 |

먼저 해 보시려면 예시로 돌려 보십시오.

```bash
python 모으기.py 보기
```

## 도구가 짚어 주는 것

이 도구는 **점수를 매기지 않습니다.** 선생님이 봐야 할 곳만 짚습니다.

| 표시 | 뜻 |
| --- | --- |
| `초안 거의 그대로 (규정상 최하점 검토)` | 학생 글과 AI 초안이 85% 넘게 겹칩니다 |
| `초안과 많이 겹침` | 65% 넘게 겹칩니다. 읽어 보고 판단하십시오 |
| `안 씀` / `너무 짧음` | 비었거나 60자 미만입니다 |
| `숫자가 없음 — 실측 근거 확인` | ③④번인데 숫자가 하나도 없습니다 |
| `빈칸 표시가 그대로 남음` | `〈 여기에 내 실행 결과 〉` 를 안 채웠습니다 |
| `실행 기록 없음 — ③번 근거 확인` | 시뮬레이터를 한 번도 안 돌렸습니다 |
| `없는 값 실행 안 함 — ③번 만점 조건` | 자료에 없는 값으로는 안 돌렸습니다 |
| `log2 비교 흔적 없음 — ④번 최상위 조건` | log2(n) 과 견준 흔적이 없습니다 |

**겹침 수치는 참고일 뿐입니다.** 짧은 글은 우연히 높게 나올 수 있고,
학생이 초안을 잘 소화해 다시 썼는데도 어휘가 겹쳐 높게 나올 수 있습니다.
숫자만 보고 최하점을 주지 마시고 **반드시 글을 읽어 보십시오.**
