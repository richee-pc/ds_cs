[자료구조04-02] 주어진 자료를 효과적으로 정렬할 수 있는 정렬 알고리즘을 이해하고 정렬프로그램을 구현한다.

1. 정렬이란 WHY

자료들을 일정 순서대로 나열한 것. 모든 과학기술 분야에서 가장 기본적이고 중요한 알고리즘 중 하나 — 자료 탐색에 필수적이기 때문.

정렬의 대상 — 레코드(record). 레코드는 필드로 구성되고, 그중 키(key) 필드로 레코드를 구별한다.

2. 고르는 기준 CHOICE

모든 경우에 최적인 정렬 알고리즘은 없다.

① 비교 횟수

값을 몇 번 쳐다보는가

② 이동 횟수

값을 몇 번 옮기는가

자료 하나가 크면 옮기는 비용이 커진다 → 이동이 적은 쪽이 유리.

3. 분류 CLASSIFY

단순하지만 비효율

삽입 · 선택 · 버블
O(n²)

복잡하지만 효율

퀵 · 힙 · 합병 · 기수
O(n log n)

4. 여덟 가지 한눈에 SUMMARY

정렬평균최악한 줄 원리

버블 n²n² 이웃끼리 비교해 교환

합병 n log nn log n 가운데서 균등 분할 후 합병

5. 핵심 코드 수업 자료 원문 · C

선택 정렬교환 최소
for(i=0; i<n-1; i++) {
    least = i;
    for(j=i+1; j<n; j++)   // 최솟값 탐색
        if(list[j]<list[least]) least = j;
    SWAP(list[i], list[least], temp);
}
삽입 정렬거의 정렬된 자료에 유리
for(i=1; i<n; i++){
    key = list[i];
    for(j=i-1; j>=0 && list[j]>key; j--)
        list[j+1] = list[j];   // 뒤로 밀기
    list[j+1] = key;
}
버블 정렬이동 최다
for(i=n-1; i>0; i--){
    for(j=0; j<i; j++)
        if(list[j]>list[j+1])
            SWAP(list[j], list[j+1], temp);
}
셸 정렬gap칸씩 건너뛰는 삽입 정렬
for( gap=n/2; gap>0; gap = gap/2 ) {
    if( (gap%2) == 0 ) gap++;   // 짝수면 홀수로
    for(i=0;i<gap;i++)
        inc_insertion_sort(list, i, n-1, gap);
}
퀵 정렬 · partition피벗은 한 번 놓이면 끝
low = left;  high = right+1;  pivot = list[left];
do {
    do low++;  while(low<=right && list[low]<pivot);
    do high--; while(high>=left  && list[high]>pivot);
    if(low<high) SWAP(list[low], list[high], temp);
} while(low<high);

왼손 low는 피벗보다 큰 값에서, 오른손 high는 피벗보다 작은 값에서 멈춘다. 둘이 엇갈리면 끝 → 피벗을 high 자리로.

7. 시험에 꼭 나오는 것 CHECK

  • 선택은 최솟값 위치만 기억했다가 한 번만 교환 → 교환 최소
  • 삽입은 list[j]>key 가 거짓이면 즉시 멈춤 → 정렬된 자료면 O(n)
  • 셸은 자료 8개면 gap이 5 → 3 → 1 (4는 짝수라 +1)
  • 퀵은 정렬된 자료에 맨 왼쪽 피벗을 쓰면 최악 O(n²)
  • 합병·힙만 최악에도 O(n log n) 보장. 합병은 추가 메모리 필요
  • 선택 기준 두 가지 — 비교 횟수, 이동 횟수
