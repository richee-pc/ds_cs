[자료구조04-03] 주어진 자료를 효과적으로 탐색하는 데 사용되는 알고리즘을 이해하고 탐색 프로그램을 구현한다.

1. 탐색이란 WHY

여러 개의 자료 중에서 원하는 자료를 찾는 작업. 컴퓨터가 가장 많이 하는 작업 중 하나이므로 효율적으로 수행하는 것이 매우 중요하다.

탐색키 — 항목과 항목을 구별해 주는 키. 탐색에 사용되는 자료구조는 배열 · 리스트 · 트리 등.

2. 10억 명 중 한 명 찾기 SCALE

순차 탐색

평균 5억 번 비교
정렬 안 되어 있어도 가능

이진 탐색

단지 30번 비교
미리 정렬되어 있어야 함

한 번 물어볼 때마다 후보가 절반으로 줄기 때문 → O(log n).

4. 개선 · 색인 · 보간 VARIANTS

개선된 순차 탐색 — 리스트 끝에 탐색키를 저장해 두면 반드시 찾게 되므로 ‘끝까지 왔나?’를 매번 확인하지 않아도 된다. 멈춘 자리가 맨 끝이면 실패.

색인 순차 탐색 — 인덱스 테이블로 구간을 좁힌 뒤 순차 탐색. 주 자료와 인덱스 테이블 모두 정렬되어 있어야 한다. (m = 인덱스 크기, n = 자료 크기)

보간 탐색이 자리를 예측하는 식

pos = low + (key - list[low]) ÷ (list[high] - list[low]) × (high - low)
이진 탐색의 (low+high)/2 자리에 이 식이 들어간 것. 불균등 분할이며, 자료가 고르게 퍼져 있으면 더 빠르다.

5. 해싱 HASHING

다른 탐색은 키 값을 비교해 찾지만, 해싱은 키 값에 대한 산술적 연산으로 테이블 주소를 계산해 항목에 직접 접근한다.

제산 함수

h(k) = k mod M
테이블 크기 M은 소수

폴딩 함수

키를 잘라 더하기
이동 폴딩 / 경계 폴딩

충돌 — 서로 다른 키 k1, k2 에 대해 h(k1)=h(k2) 인 경우.
오버플로우 — 충돌이 버켓에 할당된 슬롯 수보다 많이 발생하는 것.

좋은 해시 함수 — 충돌이 적다 · 주소 영역에 고르게 분포한다 · 계산이 빠르다.

6. 핵심 코드 수업 자료 원문 · C

순차 탐색성공 (n+1)/2 · 실패 n
int seq_search(int key, int low, int high)
{
    int i;
    for(i=low; i<=high; i++)
        if(list[i]==key)
            return i;   // 탐색 성공
    return -1;          // 탐색 실패
}
이진 탐색정렬 필수
int search_binary2(int key, int low, int high)
{
    int middle;
    while( low <= high ){
        middle = (low+high)/2;
        if( key == list[middle] ) return middle;
        else if( key > list[middle] ) low = middle+1;
        else high = middle-1;
    }
    return -1;
}

수업 자료 주석 주의 슬라이드에는 low=middle+1 옆에 ‘왼쪽’, high=middle-1 옆에 ‘오른쪽’이라 적혀 있으나 서로 바뀐 것. 가운데보다 크면 오른쪽(low 올림), 작으면 왼쪽(high 내림)이 맞다.

7. 충돌 해결 네 가지 COLLISION

선형 조사법

(h(k)+1) mod M
바로 옆칸 → 군집 문제

이차 조사법

(h(k)+inc*inc) mod M
+1, +4, +9 → 군집 완화

이중 해싱

다른 함수 h’(k) 만큼
건너뛰며 조사

체이닝

버켓마다 연결 리스트
→ 오버플로우 없음

수업 자료 예제 M = 7, 키 8 · 1 · 9 · 6 · 13 을 차례로 넣은 결과

방법012 3456
선형 · 이차138196
이중 해싱891316
체이닝8→196→13

이 예제는 모든 충돌이 한 번에 해결되어 선형과 이차의 결과가 같다. 1*1 = 1 이라 첫 재시도가 같기 때문. 두 번 이상 충돌해야 갈라진다.

슬라이드 오탈자 이중 해싱 설명의 h’(k)=5-(5 mod 5) 는 h’(k)=5-(k mod 5) 가 맞다 (계산은 h’(1)=4, h’(13)=2 로 되어 있다).

9. 시험에 꼭 나오는 것 CHECK

  • 순차 — 성공 (n+1)/2번, 실패 n번
  • 이진 — 정렬 필수. 크면 low=middle+1
  • 색인 순차 — O(m+n/m), 둘 다 정렬
  • 보간 — 위치를 예측해 불균등 분할
  • 해싱 — 평균 O(1), 최악 O(n). M은 소수
  • 충돌=같은 주소, 오버플로우=슬롯 수 초과
  • 조사법=테이블 안 빈칸, 체이닝=연결 리스트
  • 잘 찾으려고 정렬한다 — ch4 와 ch5 는 한 몸
